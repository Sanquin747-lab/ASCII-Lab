# 磁带雨 · TAPE RAIN

让记忆，下成雨。基于 ASCII LAB 的本地影像视觉台。

## 磁带雨效果

- **时间雨幕**：保留最近最多 3 秒的真实历史画面，让每一列呈现不同时间的影像。
- **磁带拖影**：历史帧横向漂移，叠加带状余像与轻微行偏移。
- **字符降雨**：亮部字符向下脱落，带有衰减尾迹。图片和文字也可产生动画。
- **动态配方**：雨夜、回放、失速，以及纯 ASCII；三种效果可以独立调节和叠加。
- **旁路对比**：临时关闭效果并保留参数。
- **我的配方**：在当前浏览器本地保存、载入一套字符样式与效果参数。

效果依次处理时间雨幕、磁带拖影、字符降雨，再生成字符画。PNG、TXT、HTML 和 WebM 导出均保留处理结果。暂停会同时冻结输入和效果。

时间雨幕需要运动素材才能产生明显变化；载入新素材、调整字符密度或视频循环时会重新积累历史。最多保留 80 帧低分辨率像素，避免缓存完整视频帧。实际帧率取决于设备和字符密度。

## 功能

- 图片、视频、摄像头、屏幕共享与中英文文字输入。
- 实时字符转换，六种字符集及自定义字符。
- 字符密度、亮度、对比度、原色与单色控制。
- 四套视觉预设，桌面和手机布局。
- 导出 PNG、TXT、独立 HTML，以及无音频 WebM 录制。

本版聚焦视觉效果；暂不包含音频驱动、关键帧时间线和原声导出。

素材始终在本机处理，不上传到服务器。摄像头和屏幕共享需要浏览器授权，推荐桌面版 Chrome 或 Edge。PDF、文档等可通过共享其可见画面转换，不直接解析原文件。GIF 使用静态帧。

## 本地使用

直接用浏览器打开 `index.html`。实时设备输入建议通过 HTTPS 或本机 HTTP 服务使用。

## GitHub Pages

在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/ (root)**，保存。

这是无依赖的静态网站，无需安装依赖、构建或配置密钥。GitHub Pages 完成部署后，网站地址会显示在 Pages 设置中。

后续更新根目录的 `index.html` 并提交到发布分支，即可更新网站。
